# MyFitAI

Responsive fitness product concept built with Vue 3, Vite, Tailwind CSS, shadcn-vue-style UI primitives, Lucide icons, Chart.js, and Motion for Vue.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and serve it locally with `npm run preview`.

## Pages

- `/` — Home and product overview
- `/features` — Product capabilities and interactive previews
- `/pricing` — Concept plans and comparison
- `/about` — Product concept and design principles
- `/contact` — Front-end-only form preview

All dashboard figures are illustrative sample data. The contact form does not transmit or store messages; the site has no backend.
